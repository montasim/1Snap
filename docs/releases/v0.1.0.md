# 1Snap 0.1.0

1Snap 0.1.0 is the first pre-release of the focused full-page screenshot extension for
Chrome.

## Highlights

- Capture a regular web page from top to bottom with one toolbar action.
- Restore the original page position after capture.
- Stitch recent frames locally into one PNG.
- Inspect real dimensions, file size, source, capture time, and frame count.
- Inspect, copy, or download the finished PNG.
- Open the result page or product website's SupportKori control when you want to support ongoing
  maintenance.

## Install

Download `1snap-v0.1.0-chrome.zip`, verify it with the accompanying SHA-256 file, extract the
archive, and load the extracted directory from `chrome://extensions` with Developer mode
enabled.

## Important limits

This is a pre-release and is not in the Chrome Web Store. Chrome-owned and other restricted
pages cannot be captured. The source tab must stay active until capture finishes.
