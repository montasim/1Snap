# 1Snap 0.1.1

1Snap 0.1.1 adds focused screenshot annotation while keeping captures and edits local to Chrome.

## Highlights

- Mark a screenshot with freehand Marker strokes, translucent Highlights, or precise Borders.
- Choose from four annotation colors and three stroke widths.
- Select, move, resize, delete, clear, undo, or redo annotations before finishing.
- Cancel an editing session without losing the previous annotation state.
- Keep annotations with recent local captures and return to them from the same result tab.
- Copy or download the annotated screenshot at its original output resolution. Annotated downloads
  use an `-annotated.png` filename.
- Use a refreshed product website with clearer typography, branded 404 and 500 pages, and a real
  preview of the annotation workspace.

## Install

Download `1snap-v0.1.1-chrome.zip`, verify it with the accompanying SHA-256 file, extract the
archive, and load the extracted directory from `chrome://extensions` with Developer mode enabled.

## Important limits

This is a pre-release and is not in the Chrome Web Store. Chrome-owned and other restricted pages
cannot be captured. The source tab must stay active until capture finishes. Captures and
annotations remain local to the browser and follow the recent-capture retention policy.
