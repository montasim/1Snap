# 1Snap support

## Capture problems

Before reporting a problem, confirm that:

- the page uses `http` or `https`;
- the source tab stayed active until capture completed;
- Chrome is version 120 or later;
- the page needs no more than 50 capture frames;
- the latest local build is loaded from `apps/extension/.output`.

For a useful report, include the Chrome version, operating system, public page URL when safe,
page dimensions, frame count, expected result, actual result, and any 1Snap error message.
Do not share sensitive screenshots or private URLs publicly.

## Development help

Run `pnpm check` first and include the failing command plus its error output. Use this repository's
Issues tab for reproducible bugs and focused feature requests when it is available.

Security concerns belong in the private process described in [SECURITY.md](SECURITY.md).

## Funding

[SupportKori](https://www.supportkori.com/montasim) is an optional funding channel. Financial
support does not change issue priority or create a private support agreement.
